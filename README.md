# Mini Message Board

A simple message board built with Node.js and Express where users can post messages and view individual message details.

## Features

- View all messages on the index page
- Submit new messages via a form
- View individual message details on a dedicated page

## Tech Stack

- Node.js
- Express
- EJS

## Getting Started

Clone the repository and install dependencies:

```bash
git clone git@github.com:rlechuong/mini-message-board.git
cd mini-message-board
npm install
```

To run in development:

```bash
npm run dev
```

To run in production:

```bash
npm start
```
